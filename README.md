# RAG PIPELINE

**My First Project**

## Overview

CS441-HW1 is a Scala-based project created as part of coursework for CS441. This repository serves as the foundation for learning and experimenting with Scala programming concepts.

## Features

- Written entirely in Scala
- Designed for educational purposes
- Simple, clean structure for easy understanding

## Getting Started

### Prerequisites

- [Scala](https://www.scala-lang.org/download/)
- [sbt (Scala Build Tool)](https://www.scala-sbt.org/download.html)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/vipulpatil04/CS441-HW1.git
   cd CS441-HW1
   ```

2. Compile and run:
   ```bash
   sbt run
   ```

## Project Structure

```
CS441-HW1/
```

## Usage

Modify the Scala files in `src/main/scala/` to add your solutions or experiments. Run the project using `sbt run`.
